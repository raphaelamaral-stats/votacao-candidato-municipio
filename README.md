# votacao-candidato-municipio
Analise de Microdados Eleitorais - TSE 2024 (Maringa e Regiao)
Sobre o Projeto
Este projeto realiza o processamento e a analise estatistica dos microdados de votacao por municipio das Eleicoes Municipais de 2024. O foco principal esta na regiao de Maringa/PR, visando extrair padroes de comportamento eleitoral e densidade de votos atraves de fontes oficiais.

Tecnologias e Ferramentas
Linguagem: Python 
            <img src="https://cdn.jsdelivr.net/gh/devicons/devicon@latest/icons/python/python-original-wordmark.svg" />
          

Bibliotecas: Pandas, Matplotlib e Seaborn

Fonte de Dados: Repositorio de Dados Eleitorais do TSE (2024)

Metodologia Aplicada
A analise e estruturada sob rigor estatistico e economico:

ETL: Extracao e limpeza dos arquivos brutos para filtragem do municipio de Maringa.

Analise Exploratoria: Identificacao de tendencias e distribuicao de votos por zona eleitoral.

Modelagem: Aplicacao de estatistica descritiva para validacao dos dados.

Estrutura do Repositorio
data/: Microdados e recortes utilizados na analise.

notebooks/: Arquivos Jupyter Notebook com o desenvolvimento passo a passo.

src/: Scripts para automacao do tratamento de dados.
